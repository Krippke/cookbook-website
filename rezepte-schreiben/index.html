Rezepte schreiben

Ein Rezept in Cookbook ist einfacher Text, so wie du ihn auch auf einen Zettel schreiben würdest. Vier Regeln reichen, damit die App Zutaten, Schritte und Tags erkennt.

Die vier Regeln

  1. 1

    Die erste Zeile ist der Name.

    Alles, was du als Erstes schreibst, wird zum Titel des Rezepts.

  2. 2

    Danach kommen die Zutaten, eine pro Zeile.

    Der Block endet an der ersten Leerzeile. Aufzählungszeichen wie • oder - darfst du setzen, musst du aber nicht.

  3. 3

    Nach einer Leerzeile beginnt die Zubereitung.

    Zusammenhängende Zeilen bilden einen Schritt. Eine Leerzeile oder eine Nummer wie „1.“ beginnt den nächsten.

  4. 4

    Tags stehen in eigenen Zeilen mit /tag.

    Egal wo im Text. Sie erscheinen als Schlagwörter und werden zum Filtern benutzt.

Zutaten: Menge, Einheit, Zutat

Eine Zutatenzeile besteht aus Menge, Einheit und Name. Menge und Einheit sind freiwillig. Brüche wie 1/2 und Kommazahlen wie 1,5 versteht die App. Die Tabelle wird beim Bauen dieser Seite von derselben Logik erzeugt, die auch in der App steckt.

Du schreibst Menge Einheit Zutat
200 g Mehl 200 g Mehl
1 TL Salz 1 TL Salz
1tl Essig 1 tl Essig
1/2 Tasse Zucker 0,5 Tasse Zucker
1,5 l Milch 1,5 l Milch
2 Eier 2 – Eier
1 Prise Salz 1 Prise Salz
Salz – – Salz
• 3 Äpfel 3 – Äpfel

Schritte: Zeilen, Leerzeilen, Nummern

Im Kochmodus zeigt die App einen Schritt pro Seite. Deshalb lohnt es sich, Schritte bewusst zu trennen.

Tags mit /tag

Eine Zeile /tag vegan hängt das Schlagwort „vegan“ an das Rezept. Tags dürfen Leerzeichen enthalten, doppelte werden ignoriert. In der App fügst du sie bequem über den Knopf „Tag hinzufügen“ ein, der genau diese Zeilen schreibt.

Häufige Stolpersteine

  • Die Leerzeile zwischen Zutaten und Zubereitung fehlt.

    Dann landet der erste Schritt in der Zutatenliste. Eine Leerzeile einfügen, fertig.

  • Eine Leerzeile mitten in den Zutaten.

    Der Zutatenblock endet an der ersten Leerzeile. Alles danach zählt als Zubereitung.

  • Eine Zeile beginnt mit einem Schrägstrich.

    Zeilen, die mit / anfangen, gelten als Befehl und werden nicht angezeigt. Ein Bindestrich davor hilft: „- /…“.

Die .recipe-Datei

Wenn du ein Rezept aus der App teilst, entsteht eine Datei mit der Endung .recipe. Darin steckt eine kleine JSON-Struktur mit dem Rezepttext und dem Foto. Empfängt jemand die Datei und tippt sie an, öffnet Cookbook das Rezept zum Prüfen und speichert es.

Für Entwickler: Das Format ist absichtlich klein. Wer Rezepte für Cookbook erzeugen will, schreibt den Text nach den Regeln oben in das Feld text.

Beispiel: Käsespätzle.recipe 
{
  "version": 3,
  "id": "27689c3f-f547-4953-a1fb-dde731d04283",
  "text": "Käsespätzle\n\n500 g Mehl\n6 Eier\n…\n\n/tag schwäbisch",
  "image": null
}
Feld Typ Bedeutung
version number Version des Dateiformats. Aktuell 3.
id string Eindeutige Kennung des Rezepts, eine UUID. Beim erneuten Import wird das vorhandene Rezept aktualisiert statt verdoppelt.
text string Der komplette Rezepttext, genau wie oben beschrieben, inklusive der /tag-Zeilen.
image string | null Das Rezeptfoto als Base64, oder null, wenn keins vorhanden ist.

Import per Link

Viele Rezeptseiten hinterlegen ihre Rezepte in einem maschinenlesbaren Format (schema.org/Recipe). Cookbook liest das aus: Teile den Link aus dem Browser an die App oder wähle im Menü „Aus Link importieren“ und füge die Adresse ein. Titel, Zutaten, Schritte und das Foto landen im Formular, du prüfst und speicherst.

Die Rezeptseiten hier auf der Website funktionieren genauso. Seiten ohne dieses Format erkennt die App nicht; dann hilft Kopieren und Einfügen des Textes.

Probier es aus

Schreib dein erstes Rezept in Cookbook. Kostenlos, ohne Konto.
